\sectionexercises{Disjoint union}

A \SetDisjointUnion is a particular type of set with two additional methods: \funcname{pack} and \funcname{unpack}.
\begin{itemize}
    \item The \funcname{pack} method constructs an element of the \SY{disjoint union} in a specified component.
    \item The \funcname{unpack} method identifies the component an element belongs to and retrieves its original value.
\end{itemize}
