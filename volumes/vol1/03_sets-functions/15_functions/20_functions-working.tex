\subsection{A function is a set of choices}
Imagine specifying a function $\mapa \colon \setA \to \setB$ element by element: for each $\ela \setin \setA$ there needs to be specified a corresponding element  $\mapa(\ela) \setin \setB$. A point of view that is sometimes useful is to interpret  a function $\mapa \colon \setA \to \setB$ as encoding a set of \emph{choices}: one choice for every $\ela \setin \setA$, namely the choice of a corresponding element $\mapa(\ela)$ in the set $\setB$. 

From this point of view, it is clear, for example, that specifying a function 
\begin{equation}
\mapa \colon \makeset{\singletonel} \to \setB
\end{equation}
from a singleton set $\singleton = \makeset{\singletonel}$ is the same thing as choosing a single element of $\setB$, namely the choice of $\mapa(\singletonel)$. Thus, from this perspective, it is clear that the set
\begin{equation}
\setB^\singleton = \makeset{ \text{ functions } \singleton \to \setB \ }
\end{equation}
is in bijection with the set $\setB$ itself. 

\subsection{A function is an indexed collection of things}
\label{sec:function-as-indexed-collection}

The previous point of view puts the emphasis on the source $\setA$: for each element of $\setA$ we make a choice of an element of $\setB$. Let us now shift the emphasis onto the \emph{results} of all these choices. Taken together, they form a collection of elements of $\setB$ --- one for each $\ela \setin \setA$ --- and the elements of $\setA$ play the role of \emph{names} for the members of this collection. From this point of view we call $\setA$ an \emph{index set}, we call its elements \emph{indices}, and we say that $\mapa$ is a collection of elements of $\setB$ \emph{indexed by} $\setA$.

This change of emphasis is often accompanied by a change of notation: instead of writing $\mapa(\ela)$ for the element of $\setB$ associated with the index $\ela$, one writes it as a subscript, say $\elb_\ela$, and one denotes the whole indexed collection by
\begin{equation}
\makeset{ \elb_\ela }_{\ela \setin \setA}.
\end{equation}
Nothing mathematical has changed here: $\makeset{ \elb_\ela }_{\ela \setin \setA}$ and $\mapa \colon \setA \to \setB$ are two ways of writing down the same data.

The reason to make this point explicitly is that indexed collections are used everywhere in mathematics, usually without any mention of functions, and it is worth realizing that, technically speaking, an indexed collection simply \emph{is} a function.

Its source is the index set $\setI$; its target is some set $\setofsetsA$ whose elements are sets; and the function itself is

\paragraph{Sequences.}
The same is true of sequences. In analysis one considers sequences of real numbers
\begin{equation}
\ela_0, \ela_1, \ela_2, \ela_3, \dots
\end{equation}
and writes them as $\makeset{ \ela_\setIel }_{\setIel \setin \natnumbers}$. Such a sequence is exactly a function
\begin{equation}
\defmapperiod{

\end{equation}
The familiar notation $\ela_\setIel$ is just the subscript notation for $\ela(\setIel)$. More generally, a sequence of elements of any set $\setB$ is a function $\natnumbers \to \setB$, and a \emph{finite} sequence, or tuple, of length $n$ is a function $\makeset{1, \dots, n} \to \setB$; this is the observation from which the unordered cartesian product in \cref{sec:arithmetic-products} was built.

It is also worth noticing what the index set contributes. The set $\natnumbers$ does not merely supply enough names for the members of a sequence: it also comes with an order, and it is this order that lets us speak of the ``first'' term, of ``later'' terms, or of what happens ``as $\setIel$ grows''. If we replace $\natnumbers$ by an index set with no order, such as $\makeset{\text{north}, \text{south}, \text{east}, \text{west}}$, we still have an indexed collection, but there is no longer any meaning to the question of which element comes first.

\begin{remark}
    A word of caution about the notation $\makeset{ \elb_\ela }_{\ela \setin \setA}$: despite the braces, an indexed collection is not the same thing as the set of its members. The set of members is the image $\mapa(\setA) \setsubseteq \setB$, and passing to it destroys information: it forgets which index produced which element, and it collapses repetitions. 
    
    
For an example about how indices are forgotten if we only consider images, consider the two functions $\makeset{1,2} \to \makeset{a, b, c, d, e, f, g}$ given by $\elb_1 = a,  \elb_2 = b$ and by $\elb_1 = b$, $\elb_2 = a$, respectively. They have the same image but are distinct functions.  

For an example about how repetitions are forgotten, consider the function $\makeset{1,2, 3} \to \makeset{a, b, c, d, e, f, g}$ with $\elb_1 = a$, $\elb_2 = a$, and $\elb_3 = a$. Its image is $\makeset{a} \subseteq \setB$, which, on its own, doesn't tell us that the family in question has, in fact, three elements. 
\end{remark}

\subsection{A function is a set of labels}

\todotext{Explain the distinction between names and labels}

Another possible interpretation of a function $\mapa \colon \setA \to \setB$ is that $\setB$ is a set of possible \emph{labels} for elements of $\setA$, and $\mapa$ assigns each $\ela \in \setA$ a label. 

For instance, $\setA$ might be a set of foods and $\setB = \makeset{ \text{fruit}, \text{vegetable}, \text{baked}, \text{candy}}$ a set of types of foods. 

Or, $\setA$ might be a set of people in a government economic database and the elements of $\setB  = \makeset{ \text{employed}, \text{unemployed}}$ mark possible states of employment.

\subsection{A function is a partition}

Given a function $\mapa \colon \setA \to \setB$, we can consider, for any $\elb \setin \setB$, it's pre-image under $\mapa$, which is the subset 
\begin{equation}
\mapa^{-1}(\makeset{\elb}) = \makeset{ \ela \setin \setA \mid \mapa(\ela) = \elb}.
\end{equation}
In other words, $\mapa^{-1}(\makeset{\elb})$ is all of those elements of $\setA$ that evaluate, under $\mapa$, to $\elb$. If we consider a $\elb$ that happens to not be in the image of $\mapa$, then its pre-image under $\mapa$ is simply the empty set. 

Now we observe that the set of all non-empty pre-images under $\mapa$ of elements of $\setB$ forms a partition of $\setA$. In other words, 
\begin{equation}
\makeset{ \mapa^{-1}(\makeset{\elb}) \mid \elb \setin \mapa(\setA) \subseteq \setB} \subseteq \powerset \setA
\end{equation}
is a partition. This is quite intuitive when drawn visually. 
\todotext{Make diagram to illustrate}

Thus, another perspective we can take is to view a function $\mapa \colon \setA \to \setB$ as something that groups together elements of the domain $\setA$ into non-empty disjoint subsets which form a partition: one subset for each value of $\mapa$. We can connect this point of view with the previous one about labels if think each value $\elb \setin \setB$ of $\mapa$ as a label for the elements of $\mapa^{-1}(\makeset{\elb})$.


\subsection{A function is a bundle}

The idea of a "bundle" comes from differential geometry and related fields. Intuitively speaking, a bundle consists of a ``base space'' $\setB$ (imagine this to be, for example, the surface of the earth), together with, for each point $\elb \setin \setB$, a set $\subA_\elb$ of possible values of something (for example, the set of possible values of temperature that could be measured at the point $\elb$). Now, the picture to imagine is of all of the sets $\subA_\elb$ hovering over the space $\setB$, forming a ``bundle over $\setB$''. 
\todotext{Make diagram to illustrate}

The sets $\subA_\elb$ are called the ``fibres'' of the bundle and the disjoint union of all the sets $\subA_\elb$ (varying over $\elb \setin \setB$) is, up to isomorphism, the ``total space'' $\setA$ of the bundle. In this situation, there is a function $\pi \colon \setA \to \setB$ which projects any element $\ela \setin \setA$ down to the element $\elb \setin \setB$ above which it ``hovers''. Returning to our example, if you give me a temperature $\ela$, which is a value somewhere in $\setA$, then $\pi(\ela)$ tells me which point on the surface of the earth this is a temperature measurement of. 

Now, the the ``bundle perspective'' on functions works like the above description, but in reverse: we start with any function $\mapa \colon \setA \to \setB$ and then we \emph{interpret} this function to be the projection function of a bundle $\setA$ over $\setB$. From this point of view, the pre-images $\mapa^{-1}(\makeset{\elb})$, with $\elb$ varying over $\setB$, are the fibres of this bundle.
