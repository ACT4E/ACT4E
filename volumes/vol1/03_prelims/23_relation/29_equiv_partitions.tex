\section{Equivalence relations}

\SY{Equivalence relations} are a way to group together elements of a set that we wish to think of as ``the same'' in some respect and in a way that creates a so-called partition of the set.
Partitions and equivalence relations appear all over mathematics.

\subsection{Partitions}

Let's start with a simple example to illustrate the idea of grouping together elements of a set into a partition.
Consider a set that consists of 10 different foods in total, and is made up of three bread-like foods, two desserts, four fruits, and one cheese.
Now suppose that we want to tell someone only the main \emph{kinds} of food that are in our set.
Then we don't need to include any information about how many fruits, desserts, etc. there are, we only want to communicate the fact that there are the following four kinds of food: bread-like, desserts, fruit, and cheese.

\begin{marginfigure}
    \centering
    \includesag{set_of_food_partition}
    \caption{A partition of a set of foods.}
    \label{fig:partition_kinds_of_foods}
\end{marginfigure}

On a mathematical level, one way to go from the ten-element set of \emph{foods} to a four-element set of \emph{kinds of foods} is to partition the ten-element set of foods into disjoint subsets, where each subset contains only the foods of a given kind.
Then we can think of these four subsets as \emph{representing} or \emph{signifying} the four kinds of food in question (and we can simply ignore how large each of these subsets is, because that is not relevant to the question of how many \emph{kinds} there are).
In other words, the four subsets in the partition can play the role of ``names'' for the four kinds of food.

Let's start to make the ideas in the above example more precise by defining partitions.
Given any set $\setA$, a partition of $\setA$ is a collection of subsets of $\setA$ which, on the one hand, are pairwise disjoint (they don't intersect) and on the other hand the union of all the subsets in the collection is equal to $\setA$.
In other words, the collection of subsets ``covers'' all of $\setA$.

\begin{ctdefinition}[Partition]
    \label{def:partition}
    A \maindef{partition} of a set~\setA is

    \constit
    \begin{enumerate}
        \item A set~$\makeset{\setA_\setIel}_{\setIel\setin \setI}$ of subsets~$\setA_\setIel\setsubseteq \setA$
    \end{enumerate}
    \condit
    \begin{enumerate}
        \item If $\setIel\neq \setJel$,  then $\setA_\setIel\setintersection \setA_\setJel=\Emptyset$;
        \item $\bigsetunion_{\setIel\setin \setI}\setA_\setIel=\setA$.
    \end{enumerate}
\end{ctdefinition}

    \subsection{Equivalence relations}

    Every partition on a set $\setA$ can be described, and defined, using a special kind of endorelation $\relA \subseteq \setA \cartprod \setA$, called an equivalence relation on $\setA$.

    Conversely, any partition on $\setA$ defines a corresponding equivalence relation.

    The correspondence between partitions of $\setA$ and equivalence relations on $\setA$ is bijective: we can translate from the one description to the other and back again without losing any information.

    To see how this works, let's suppose first that we have a partition $\makeset{\setA_1, \setA_2, \setA_3, \setA_4}$ of a set $\setA$, for example as in \cref{fig:partition_kinds_of_foods}.
    We define a corresponding relation $\relA \subseteq \setA \cartprod \setA$ as follows:

\begin{ctdefinition}[Equivalence relation]
    \label{def:equivalence-relation}
    An \maindef{equivalence relation} on a set $\setA$ is

    \constit
    \begin{enumerate}
        \item An endorelation~$\relA\subseteq \setA \cartprod \setA$;
    \end{enumerate}
    \condit
    \begin{enumerate}
        \item  \SY{Reflexivity}: $\ela \relA \ela$;
        \item \SY{Symmetry}: if $\ela \relA \elb$, then $\elb \relA \ela$;
        \item \SY{Transitivity}: if $\ela \relA \elb$ and $\elb \relA \elc$, then $\ela \relA \elc$;
    \end{enumerate}

    \textbf{Notation}: If $\relA$ is an equivalence relation, we often write~$\ela\equival_\relA \elb$, or simply $\ela\equival \elb$, instead of~$\inrel{\ela}{\relA}{\elb}$.
\end{ctdefinition}

\begin{lemma}
    There is a one-to-one correspondence between \SY{equivalence relations} on a set~\setA and partitions of~\setA.
\end{lemma}

\begin{example}
    The relation ``equals'' on~\natnumbers is an \SY{equivalence relation}.
    The relation ``less than or equal'' on~\natnumbers is not.
\end{example}

\begin{example}
    The relation on~\natnumbers ``differing by a multiple of 3''
    \begin{equation}
        \prfdoubleperiod{
            \inrel{\ela}{\relA}{\elb}
        }{
            (\ela-\elb) \mod 3 = 0
        }
    \end{equation}
    is an \SY{equivalence relation}.
    Indeed, the relation is \SY{reflexive}, and \SY{symmetric}.
    Furthermore, if~$\ela$ differs by a multiple of 3 from~$\elb$ and~$\elb$ differs by a multiple of 3 from~$\elc$, then~$\ela$ differs by a multiple of 3 from~$\elc$ (transitivity).
\end{example}

\begin{example}
    The relation ``has the same birthday as'' on the set of all people is an \SY{equivalence relation}.
    It is \SY{symmetric}, because if Anna has the same birthday as Bob, then Bob has the same birthday as Anna.
    It is \SY{reflexive} because every person has the same birthday as themselves.
    % It is \SY{transitive} because if Anna has the same birthday as Bob, and Bob has the same birthday as Clara, then Anna has the same birthday as Clara.
\end{example}

\begin{example}
    Let~$\mapa\colon \setA \sto \setB$ be a function between sets.
    The following defines an \SY{equivalence relation} $\equivalparam{\mapa}$ on the set $\setA$:
    \begin{equation}
        \prfdoubleperiod{
            \ela\equivalparam{\mapa} \elb
        }{
            \mapa(\ela)=\mapa(\elb)
        }
    \end{equation}
\end{example}

    We can use the notion of isomorphism to make a more formal definition of the size, or cardinality, of a set, as follows.
    First we posit that any set \setA has an attribute which we call its cardinality, and denote by $\cardof \setA$ (as before).
    Then we say that for any two sets, \setA and \setB, it shall hold that

            \cardof \setA = \cardof \setB

            \setA \simeq \setB
