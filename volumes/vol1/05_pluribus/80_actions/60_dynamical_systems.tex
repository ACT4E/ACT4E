\section{Dynamical systems}
\label{sec:dynamical-systems}

Dynamical systems are ubiquitous in engineering, and there are various ways to formulate this concept mathematically. At a very basic level, there are usually the following ingredients:
\begin{enumerate}
    \item a \emph{state space} which comprises the possible states of the system in question
    \item a \emph{dynamics rule} which governs how states of the system may change
\end{enumerate}
Typically, there is a model of \emph{time} involved (e.g. either in discrete time-steps, or as continuous time) for describing how states change over time, or, instead of a model of time, one may use a set of \emph{events} as the triggers for changes of state.

A common way to model dynamics is by a right action operation of a monoid $\mathbf{T} = \tup{\stylesets{T}, \mthen_{\mathbf{T}}, \idmon_{\mathbf{T}}}$ on a set $\stylesets{X}$ which models the state space,
\begin{equation}
\stylefunctors{\aword{dyn}} \colon  \stylesets{X} \cartprod \stylesets{T} \sto \stylesets{X}.
\end{equation}

\subsection{Discrete time systems}

Consider for example the monoid $\mathbf{T} = \tup{\natnumbers, +, 0}$ as a discrete model of time. Observe that $\mathbf{T}$ is generated by the number $1 \setin \natnumbers$: every natural number $n$ can be written as a $n$-fold sum of $1$ with itself. If we model the dynamics of a dynamical system by a left action operation of $\mathbf{T}$ on a state space $\stylesets{X}$, 
\begin{equation}\label{eq:discrete-time-dynamics}
\dyn \colon  \stylesets{\natnumbers} \cartprod \stylesets{X}   \sto \stylesets{X},
\end{equation}
then in particular the dynamics is compatible with the summing of natural numbers (which is the composition operation in the monoid $\mathbf{T}$):
\begin{equation}
        \dyn(n, \dyn(m, x) = \dyn(n + m, x).
\end{equation}
Thus, because $\mathbf{T} = \tup{\natnumbers, +, 0}$ is generated by the number $1$, the function \cref{eq:discrete-time-dynamics} is completely determined by the function
\begin{equation}\label{eq:discrete-dynam-generating}
\dyn(1, - ) \colon \stylesets{X}   \sto \stylesets{X}. 
\end{equation}
If we start `running' the dynamical system at some point $x_0$ at time $t = 0$, then iteratively applying the function \cref{eq:discrete-dynam-generating} will compute that trajectory $x_0, x_1, x_2, x_3, \dots$ of the initial point $x_0$ as time progresses.
Often a discrete-time dynamical system is specified by defining the function \cref{eq:discrete-dynam-generating} in the following notation,
\begin{equation}
x_{n+1} = \mapa(x_n), 
\end{equation}
where $\mapa = \dyn(1, - )$ and $x_n$ denotes $\dyn(n, x_0)$, the $n$-th element of a trajectory starting at some $x_0$. 
 





\subsection{Continuous time systems}

Consider the initial value problem
\begin{equation}
\begin{cases}
\dot{\stylemaps{x}}(t) = \mapa(\stylemaps{x}(t)) \\
\stylemaps{x}(0) = x_0
\end{cases}
\end{equation}
where $\mapa \colon \reals^n \sto \reals^n$ is a differentiable function, $\stylemaps{x} \colon \reals \sto \reals^n$ is a continuously differentiable function, and $x_0 \setin \reals^n$. Under suitable assumptions on $\mapa$, for each choice of $x_0$, there exists a unique solution $\stylemaps{s}_{x_0} \colon \reals \sto \reals^n$ of this initial value problem. \begin{definition}[Continuous-time dynamical system]
    \label{def:ct-dynsyst}
    
    A continuous-time dynamical system on~$\reals^n$ is a continuously differentiable function
\begin{equation}
\varphi \colon \reals \cartprod \reals^n \to \reals^n
\end{equation}
such that 
\begin{enumerate}
\item $\varphi(t + s, x) = \varphi(t, \varphi(s,x)) \quad \forall t, s \setin \reals, x \setin \reals^n$,
\item $\varphi(0, x) = x \quad \forall x \setin \reals^n$.
\end{enumerate}

\end{definition}
