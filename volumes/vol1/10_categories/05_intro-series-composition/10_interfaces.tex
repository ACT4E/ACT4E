To think about series composition, let's start off with a toy example: composing electrical extension chords. Each chord has a certain length, and we can stick chords together to obtain a (composite) extension chord of greater length:
%


\begin{equation}
    \prfperiod{
        \cordG{a}
    }{
       \cordG{b}
    }{
        \cordG{a + b}
    }
\end{equation}
%
If we use a unit of length so that it suffices for our model to consider lengths given by natural numbers, then we could say that this model is very similar to the semigroup $\tupp{\natnumbers,+}$, because composing chords end-to-end means that the resulting length is the sum of the component chord lengths. 

In this model so far, \emph{any} two chords may be composed by being set end-to-end. However, worldwide there is a handful of different types of electrical plugs and sockets (see \cref{fig:plugs}), so let's expand our model to allow for chords whose plug end and socket end might be of different types. We'll use little country flags as indicators of the types of the plugs and sockets: 
\begin{equation}
    \label{eq:want}
    {\cord{\TypeIrish}{a}{\TypeSwiss}}
\end{equation}

In this expanded model, we can no longer compose \emph{any} two chords; we can only connect one chord with another   if the  \emph{type of the plug} of the one is the same as the \emph{type of the socket} of the other:
\begin{equation}
    \label{eq:irish-swiss-result}
    \prfperiod{
        \cord{\TypeIrish}{a}{\TypeIrish}
    }{
        \cord{\TypeIrish}{b}{\TypeSwiss}
    }{
        \cord{\TypeIrish}{a + b}{\TypeSwiss}
    }
\end{equation}


Or, phrased in a slightly more abstract manner, for any plug/socket types $\Obja, \Objb, \Objc$ the general formula to compose chords is
%
\begin{equation}
    \label{eq:cords-generic}
    \prfperiod{
        \cord{\Obja}{a}{\Objb}
    }{
        \cord{\Objb}{b}{\Objc}
    }{
        \cord{\Obja}{a+b}{\Objc}
    }
\end{equation}
 
If we think of the ends of the chords as ``interfaces'', then we can say that two chords are only then composable at a pair of interfaces when those interfaces match. In this statement, there are in fact two conditions at play: for interfaces to match we need 1) that one of the interfaces is a plug and the other is a socket, and 2) we need that both interfaces have the same type. This pattern, as described in \cref{eq:cords-generic}, appears all across mathematics and real-world applications. We'll list a few selected examples to illustrate. 

\paragraph{Sets and functions}
Let $\setA$, $\setB$, and $\setC$ be sets. Given a function $\mora \colon \setA \to \setB$ and a function $\morb \colon \setB \to \setC$, we can compose them in series via the usual notion of function composition: 
\begin{equation}
\defmapperiod{
\mora \mthen \morb
}{ \setA
}{ \to
}{ \setB
}{ \ela
}{ \morb(\mora(\ela))
}
\end{equation}
In other words, 
\begin{equation}
    \label{eq:cords-generic}
    \prfperiod{
        \cord{\Obja}{a}{\Objb}
    }{
        \cord{\Objb}{b}{\Objc}
    }{
        \cord{\Obja}{a+b}{\Objc}
    }
\end{equation}

\paragraph{Pre-orders and monotone functions} Consider now, instead of just sets and functions, pre-orders and monotone functions between them. Again we can compose such functions when their ``interfaces'' match:
\begin{equation}
    \label{eq:cords-generic}
    \prfperiod{
        \cord{\Obja}{a}{\Objb}
    }{
        \cord{\Objb}{b}{\Objc}
    }{
        \cord{\Obja}{a+b}{\Objc}
    }
\end{equation}

This works, in particular, because the (series) composition of two monotone functions is, automatically, also monotone function. This was noted in REF as the ``compositionality'' of monotonicity. 


\paragraph{Monoids and monoid morphisms} Similar to the case of pre-orders and monotone functions, we have seen in REF that we can compose monoid morphisms, provided their interfaces match, and the result is again a monoid morphism:
\begin{equation}
    \label{eq:cords-generic}
    \prfperiod{
        \cord{\Obja}{a}{\Objb}
    }{
        \cord{\Objb}{b}{\Objc}
    }{
        \cord{\Obja}{a+b}{\Objc}
    }
\end{equation}


\paragraph{Real coordinate spaces and real matrices}
Consider real coordinate spaces $\reals^k$, $\reals^m$, and $\reals^n$. An $m \times k$ real matrix encodes a linear function $\mat{A} \colon \reals^k \mto \reals^m$, and an $n \times m$ real matrix encodes a linear function $\mat{B} \colon \reals^m \mto \reals^n$. Because the target space of the first matrix matches the source space of the second matrix, they can be composed in series via matrix multiplication, and the result is a matrix of the appropriate dimensions: 
\begin{equation}
    \label{eq:cords-generic}
    \prfperiod{
        \cord{\Obja}{a}{\Objb}
    }{
        \cord{\Objb}{b}{\Objc}
    }{
        \cord{\Obja}{a+b}{\Objc}
    }
\end{equation}
